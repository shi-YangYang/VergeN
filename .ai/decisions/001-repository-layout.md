# 沿用客户端和运维服务的原生工程边界

维护者要求清理根目录并统一代码、测试、环境文件的位置。桌面端的 Vite、Tauri 和 Cargo 共用仓库根工作区，Android 的 Gradle 和内核子模块位于 android/，Go 的内部包及面板构建产物位于 server/。整体迁入 apps/ 会牵动客户端打包、CI 缓存和服务端嵌入路径。

保留上述工程入口；在业务包内部按功能归位，将散置的测试、环境配置与维护文档归到相应目录。移除多余的根说明文件。跟踪文件的迁移可从整理前的提交恢复；忽略的环境文件需要单独移动并保持原权限。

打包配置迁至 `config/env/.env.build.local`。旧工作副本仅有根部同名文件时，打包工具继续读取该文件并提示迁移。回退至旧代码时把私有配置移回根部；目标已有文件时应先对照合并。
