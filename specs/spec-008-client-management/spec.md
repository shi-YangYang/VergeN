# 运维导航与客户端管理

## 背景与目标
原发布页同时展示表单、历史和文件库。Windows 选择框已有后缀校验，但系统文件窗口仍可能列出其他文件；桌面在线更新区的平台名、选择框和签名按钮未对齐。

## 目标行为
管理员登录默认进入 Dashboard，菜单第一项也是 Dashboard。员工账号页保留客户端信息，不再展示「最近在线」。公共下载页的访问规则不变。

「客户端管理」分为发布版本、已有版本、文件库三个可直接访问的子页；切换子页保留当前发布草稿。手机也能访问三个入口。版本及文件删除、签名校验沿用原规则。

## 范围与兼容性
通过文件夹筛选时，页面只列出符合当前平台、用途和版本的文件；同名签名配套匹配。不上传整个文件夹。仍可单选文件，支持时关闭原生选择器中的“所有文件”；原生窗口如何绘制不可选项由浏览器和系统决定。Windows 仅 EXE；macOS 安装包与升级归档分别选择；Linux 仅 DEB；Android 仅 APK。文件库保留不同版本的原有文件。

- [x] 检查三个独立入口、直达刷新、返回和草稿保留。
- [x] 用不同版本、平台及签名验证文件候选和上传限制。
- [x] 比较桌面在线更新行的坐标，检查手机堆叠与文件长名称。
