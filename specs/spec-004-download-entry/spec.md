# 下载时登录，而不是浏览时登录

## 背景与当前行为

员工先在钉钉工作台登录才能看版本列表；点击安装包切到系统浏览器后，浏览器没有工作台的 Cookie，又要登录一次。

## 目标与功能需求

任何人都可以浏览平台、版本、更新说明和安装包名称。下载指定文件、打开个人订阅时才要求企业钉钉身份。匿名点击「使用 Clash Mi」提示需要公司钉钉登录；取消留在目录，确认后才进入授权。已有有效会话直接继续。

## 边界与兼容

公开列表不提供可绕过登录的外部直链或个人订阅地址。认证后仅续接原本站操作。查看订阅弹窗不占用地址；员工明确点击复制后才领取。保留管理员权限、客户端更新票据及登录中的旧文件链接。不新增 macOS 订阅功能；macOS 下载 DMG，个人订阅沿用 iOS 的 Clash Mi 入口。

## 验收标准

- [x] 未登录可从首页进入目录和切换版本；安装文件仍需登录。
- [x] 文件登录成功自动续下原文件；取消授权后重试保留目标。
- [x] 点击「使用 Clash Mi」时提示登录，取消可继续浏览；登录成功回到订阅弹窗；未登录不得获取地址，打开弹窗不分配地址。
- [x] 同一浏览器复用有效会话，无需重复授权。
