# 首轮验收发现的边界

- Windows：LAN 与每个 RAS/VPN 连接是独立的系统代理。员工后来改动、新增或删除一个 VPN 连接时，保留这项改动，仍须还原其他由 VergeN 接管的连接。
- Linux：KDE 的 kioslaverc 与桌面应用共用的 GSettings 可能各自被修改。不能因为一个已变动就留下另一个无效的本地代理。
- macOS：已有特权服务在 StartClash、StopClash 或 SetSystemProxy 执行时选择活动网络，其选择可能与发请求前不同。请求前必须保护所有可能被改写的有效代理策略，或把写入绑定在已验证的网络上。避免为本来直连的网络阻断单纯的内核/TUN 操作。

回归使用隔离的多配置测试：一处由第三方修改而其他仍由 VergeN 接管；恢复期间配置列表有变动；macOS 在变更网络及无活动接口时遇到不可恢复的公司配置。
