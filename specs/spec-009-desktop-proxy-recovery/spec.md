# 桌面系统代理的恢复

## 背景与目标
员工开启系统代理后直接关机。若退出清理没有完成，下一次登录操作系统时，即使不开 VergeN，也应能按接管前的配置用网。维护者在本次对话确认了这个问题记录及下列范围。

## 行为与边界
- 在首次改变系统设置前，按用户及实际的系统网络配置持久保存原设置，登记 VergeN 的目标，准备好登录时的一次性恢复入口。切换端口、PAC 或重复应用时不丢失原设置。
- 退出、主动关闭或下次系统登录时，只还原仍可确认由本客户端写入的设置。必须保留原本的直连、手动代理、绕过列表或 PAC。无记录、别人更改了设置、另一个接管仍然有效时不强制关闭。
- 登录恢复不需要 WebView、企业会话、网络请求或主界面；不开 GUI 自启也有效。恢复不改变“启用系统代理”的用户偏好。主客户端只在内核可用时接管。
- 限桌面 Windows、macOS、Linux。Android 的 VpnService 配置随 VPN 生命周期生效，不修改；不改运维端。不添加常驻进程，不承诺同一次登录期间的崩溃即时恢复，不猜测旧版没有记录的原配置。

## 验收
用隔离的配置模拟接管、进程中断、再次登录以及重新接管；覆盖原有公司代理、PAC、第三方改动、无记录、重复恢复、后台仍在工作及写入失败。检查三端触发入口和权限边界，不对员工的真实代理执行测试。
