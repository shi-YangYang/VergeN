# 切换订阅后刷新代理页

## 背景与目标
员工切换到另一份订阅后，代理页仍显示旧的代理组或节点。目标是让列表跟随已经生效的订阅，不靠定时轮询或用户手动刷新。

## 需求与边界
以两份有不同节点的本地测试订阅复现，区分运行中内核与页面快照。首页、订阅页等实际切换入口沿用同一生效标准。失败不显示未生效的节点；连续切换时最终显示最后成功生效的一份。检查桌面共用实现和独立 Android；不改订阅内容、服务器或未受影响的平台。处理等待与缓存不代表缩短内核加载订阅本身的时间。

## 验收
- [x] 修改前记录可重复的失败；修改后运行相同场景得到正确的代理组与节点。
- [x] 在源头区分不同订阅与同一订阅的重复通知，保留既有出错处理，避免旧快照再覆盖已生效订阅。
