# 登录后的员工公告弹窗

旧桌面客户端只在密码登录表单显示缓存公告；Android 不展示。目标是在 macOS、Windows、Linux 和 Android 的已登录界面展示当前下发的公告，登录页和后台不弹，不打断 VPN。

登录后首次进入客户端时立即检查一次，此后每累计使用 5 分钟前台时间再检查。退到后台暂停计时；返回前台只继续剩余时间，不立即检查，也不补查后台期间错过的周期。应用内切换页面沿用当前检查及计时，不重复请求或推迟到期检查；在后台不轮询。无需重登或重新拉订阅。显示标题、纯文本正文和「我知道了」。服务端按员工账号、公告 ID 和内容版本永久记录确认，不按数量或时长淘汰。同一员工在任一设备确认并同步后，其他设备下次检查也不再收到该版；新版本或另一员工不受影响。离线确认和升级前的本机确认不丢弃，待同步成功再清理。未下发、已撤回或已删除的公告不再展示。网络不可用可在后续检查恢复，不阻塞现有使用。

验收：在线发布、确认后重复检查/重开、改发新版、撤回、切换账号、登录页和后台不弹。沿用单条公告下发和企业登录权限，不做系统推送或面向管理员的全员阅读报表。

撤回只操作选中的公告；旧页面操作已删除对象不得改变当前公告。草稿与幂等操作不更改 VPN 配置版本。桌面轻量模式重建窗口不等于重新登录；Android 锁屏、权限提示等不可交互期间暂停计时，退出账号后取消请求。
