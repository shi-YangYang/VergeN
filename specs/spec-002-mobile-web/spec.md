# 手机运维与员工下载

## 背景

员工从钉钉或手机浏览器进入下载页。管理员也需要在手机上查看账号、订阅、版本和 iOS 地址。

## 目标

让员工快速找到手机平台，让管理员用单手切换常用页面、查找记录和执行操作。

## 非目标

本次只调整 Web 界面。原生客户端、认证、订阅分配和发布 API 沿用现有实现。

## 当前行为

员工先看到 Windows 和 macOS。运维各页从侧栏进入，新建表单占据列表上方空间。iOS 管理表最小宽度为 740px。

## 目标行为

手机端优先展示 Android 和 iOS 下载入口。运维端可直接进入常用页面，按需打开新建表单、历史版本与文件库。iOS 地址的状态和操作在同一张手机卡片上。

## 功能需求

- 手机端保留全部导航项及退出入口。
- 切换下载版本时，使用该版本的说明和安装包。iOS 领取入口沿用当前版本规则。
- iOS 管理沿用筛选、搜索、分页、地址预览、查看、撤销和导入操作。

## 边界条件

覆盖 320px 窄屏、钉钉内置浏览器、长地址及较多记录。弹窗、键盘和底部导航须能共存。

## 技术约束

沿用 MUI、现有配色、消息反馈和数据处理逻辑。

## 兼容性要求

宽屏保留现有侧栏、表格及桌面平台下载方式。横竖屏切换应保留正在填写的内容。

## 验收标准

- [x] 手机常用页面可直接切换，其他页面和退出可以从更多入口到达。
- [x] 地址记录、筛选和操作在窄屏内可见。
- [x] 员工可选择版本、找到手机或电脑安装包、打开 iOS 对话框。
- [x] 手机和桌面均可进入发布流程，查看历史与文件。

## 待确认问题

无。
