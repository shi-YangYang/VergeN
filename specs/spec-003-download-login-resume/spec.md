# 员工登录后续接下载

## 背景与当前行为

钉钉工作台与系统浏览器分别保存登录会话。员工在工作台选定安装包后，系统浏览器首次访问文件地址会看到 JSON 错误。

## 目标与目标行为

打开本站安装包时，已登录的员工直接下载。浏览器缺少员工会话时走已有钉钉登录；成功回调后自动下载最初选定的文件。只访问下载列表时，登录成功仍返回列表。

## 非目标

外链由对应文件服务处理。客户端更新票据、管理员登录和 iOS 订阅领取沿用原流程。

## 功能需求和边界条件

- 支持历史版本、中文、空格及其他合法文件名。
- 中途取消后可使用错误页的重试入口。不同标签页的授权不得串到其他文件。
- 服务端只根据合法安装包文件名构造同站下载路径。员工身份、所属企业和 OAuth 状态校验仍然生效。

## 技术约束和兼容性要求

使用已有钉钉回调和员工会话。文件内容沿用现有附件响应；API 调用和带票据的更新请求继续沿用原协议。

## 验收标准

- [x] 用空 Cookie 开始，通过模拟的钉钉授权后，重定向链的最后一跳返回所选文件内容和附件名。
- [x] 已登录直接下载、普通网页登录、错误重试和访问控制均有对应验证。

## 待确认问题

无。
