# 员工下载续接验收

## Result

PASS。独立审阅确认回跳仅使用本站文件名，复用员工身份、企业和 OAuth 状态校验。

## Spec Coverage

已验证直接下载、未登录时的登录续接、访问列表、取消并重试，以及两个标签页选择不同文件的回调。过期和错文件的更新票据仍按原协议拒绝。

## Validation

S3，涉及员工登录回调。Go API 测试及前端构建通过。在 Chrome 中使用两个隔离会话，获得真实下载链接后由新浏览器打开，取消一次模拟授权并重试。授权后浏览器自动收到所选 APK，文件名及正文与原文件一致。相同请求在原版和回滚副本都返回 401。

## Issues

本地使用模拟钉钉身份。真实工作台唤起系统浏览器和生产回调尚待部署后实测。

## Regression Risks

浏览器清除登录流程 Cookie，或五分钟内未完成授权时，需从原下载链接重新发起。
