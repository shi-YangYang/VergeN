# 网页登录时长

## 背景与目标

员工下载页的登录仅保留 8 小时，管理员关闭标签页后需要重新输入密码。延长员工下载会话，并让管理员自主选择是否记住这台设备。

## 需求、边界与兼容

- 企业钉钉签发的员工下载会话自登录起有效 30 天；仍需核验账号、绑定和企业。只改变下载会话，不延长授权临时状态、更新票据或原生客户端令牌。
- 管理员登录页默认不勾选「在此设备保持登录 7 天」。不勾沿用标签页会话；勾选后关闭、重开浏览器仍可进入运维面板。
- 七天从成功密码登录起算，不因访问或续期延长。保留原有短效访问令牌；持久凭据不交给网页脚本。退出后不能再用原设备凭据恢复，停用或不再是管理员的账号不得恢复。

## 验收

核对员工 Cookie 和令牌过期时间。验证管理员已选、未选、七天到期、退出、失效账号和原生客户端凭据隔离，使用独立浏览器会话检验关闭和重开。
